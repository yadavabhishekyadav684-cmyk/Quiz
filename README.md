# JavaScript MCQ Quiz

A small, browser-based quiz for practicing JavaScript interview questions. Answer five multiple-choice questions and submit the form to see your score.

## Features

- Five questions covering JavaScript fundamentals
- Instant score display after submission
- Answers reset after each submission so you can try again
- No frameworks, package installation, or build step required

## Run the project

1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Select an answer for each question and click **Submit**.

## Project files

- `index.html` — quiz questions and page structure
- `style.css` — page and quiz styling
- `first.js` — answer checking, score calculation, and form reset

## Scoring

Each correct answer is worth one point. The result is displayed as a score out of five.
